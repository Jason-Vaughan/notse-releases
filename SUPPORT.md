# Support

Need help with Notse? Here's where to go.

## Get the latest version

Always start by making sure you're on the [latest release](https://github.com/Jason-Vaughan/notse-releases/releases). Many issues are already fixed in newer builds.

The Mac app also checks for updates automatically — open **Notse → Settings → Check for Updates**.

## Report a bug

Found something broken? **[File a bug report in Issues.](https://github.com/Jason-Vaughan/notse-releases/issues/new?template=bug_report.yml)**

To help us fix it fast, please include:
- **Notse app version** — shown in *About Notse* (Mac) or the Notse window title bar
- **Helper version** — shown in the helper's tray menu
- **Operating system** — Mac (which version) and/or Windows (which version) for the helper machine
- **What happened**, and **what you expected to happen**
- **Steps to reproduce** if you can — even an approximate sequence helps
- **Logs or screenshots** if available

The bug template walks you through these fields.

## Propose a feature or share an idea

Have an idea for what Notse should do next? **[Start a discussion under Ideas.](https://github.com/Jason-Vaughan/notse-releases/discussions)**

Discussions is the right place for:
- Feature requests
- Workflow questions
- Show-and-tell ("here's how I use Notse on my rig")
- General Q&A

We read every one. Some land in the public roadmap; some inform private design decisions; some prompt follow-up conversations.

## Licensing & purchase questions

For questions about your license key, payment, or activation, email **support@jasonvaughan.com** or visit [jasonvaughan.com](https://jasonvaughan.com).

## What about the source code?

Notse's source is hosted privately. This repo only holds release artifacts and is the public face for support and feedback. If you want to dig into the architecture or contribute beyond bug reports and feature requests, reach out via the channels above.
