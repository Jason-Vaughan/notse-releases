# Notse Releases

Public download location for **Notse** — a networked live teleprompter for broadcast / live event production.

## Get the app

Pre-built Mac DMGs are attached to releases on the [Releases page](https://github.com/Jason-Vaughan/notse-releases/releases).

## What is Notse?

Notse hooks into a running PowerPoint presentation, pulls the speaker's notes in real time, and displays them in a formatted teleprompter window with optional NDI output. It runs across two machines (graphics + operator) connected over WebSocket.

The application requires a valid license key to use. License keys are sold separately.
